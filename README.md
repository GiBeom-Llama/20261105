# 위험물 Quiz

경북전문대학교 소방안전공학과 학생용 위험물기능사 필기 대비 퀴즈입니다.

- 퀴즈 주소: https://gibeom-llama.github.io/20261105/
- 문제 86개(객관식 41 · 단답식 22 · O/X 23), 제1류~제6류 × 난이도 A(기초)·B(중급)·C(심화)
- 휴대폰에서 링크만 열면 됩니다. 설치나 로그인이 필요 없습니다.

## 사용 방법

1. 학번과 이름을 입력합니다.
2. 류·난이도별 연습, 객관식, 단답식, O/X, 종합 20문제 중 하나를 고릅니다.
3. 답을 고르면 바로 정답과 해설이 나옵니다.
4. 결과 화면에서 점수와 틀린 문제를 확인합니다. 결과는 교수님께 제출되고, 자동 제출이 안 되면 제출 코드(WQ1-)가 나옵니다.

## 관리자(교수용)

- claude.ai 퀴즈 링크의 관리자 모드에서 제출 기록, 학생별 답안, 통계를 보고 엑셀(5개 시트)로 내려받습니다.
- 구글 시트 연동을 켜면 이 주소 뒤에 `#admin`을 붙인 페이지에서 관리자 키로 같은 기능을 씁니다.

## 파일

| 파일 | 설명 |
| --- | --- |
| `index.html` | 퀴즈 앱 전체(화면, 문제 86개, 채점, 관리자 모드) |
| `google-apps-script.gs` | 구글 시트에 제출 기록을 저장하는 Apps Script. `ADMIN_KEY`는 직접 정해서 넣습니다 |
| `CLAUDE.md` | Claude Code로 문제를 추가·수정할 때의 구조와 규칙 |

## 문제 수정 규칙

- 문제는 `index.html` 안의 `QUESTIONS`(객관식), `OX`, `SA`(단답식) 배열에 있습니다.
- 제출 기록이 문제 번호로 답안을 저장하므로 기존 문제를 지우거나 순서를 바꾸지 말고, 새 문제는 배열 끝에 추가합니다.
- 문제와 해설은 현행 위험물안전관리법 기준으로 쓰고, 배포 전에 정답을 검토합니다.
