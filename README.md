# 위험물 Quiz

경북전문대학교 소방안전공학과 학생용 위험물기능사 필기 대비 퀴즈입니다.

- 퀴즈 주소: https://gibeom-llama.github.io/20261105/
- 문제 86개(객관식·단답식·O/X), 제1류~제6류 × 난이도 A(기초)·B(중급)·C(심화)
- 학번·이름을 입력하고 풀면, 결과 화면에 점수와 해설, 제출 코드(WQ1-)가 나옵니다.
- 학생은 제출 코드를 교수님께 보내고, 교수님은 claude.ai 퀴즈의 관리자 모드에 붙여넣어 점수·답안·통계를 확인하고 엑셀로 내려받습니다.

이 페이지에서는 자동 제출, 관리자 모드, 엑셀 내려받기가 동작하지 않습니다(claude.ai 링크 전용 기능).
